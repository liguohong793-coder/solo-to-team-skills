# 跟做：把一段会议转写整理成要点（完整小任务）

> English: [README.en.md](README.en.md)（同一任务的完整英文跟做）。

这是一件**低依赖的文本小任务**：不用联网、不用登录、不碰任何账号。记事本加一个文件夹就能跟做；装好了 Agent 工具，就把下面的指令交给助手。人名、内容全部虚构。

本目录的文件：

| 文件 | 是什么 |
|---|---|
| [`input.md`](input.md) | 给定输入：一段会议转写 |
| [`output-ok.md`](output-ok.md) | 成果样例：能通过验收的样子 |
| [`output-missing.md`](output-missing.md) | 成果样例：缺项，应退回 |
| [`register-lines.md`](register-lines.md) | 这件活从派出到验收的全部登记行（通过分支＋缺项分支） |

**先分清两件事。** 各家宿主的走通记录（见上级 [`examples/README.md`](../README.md)「验证环境」）证明的是「能装、能按名调用、能产出一行登记行」；本页演示的是**一件完整小任务**从输入走到验收。本页样例由作者照方法写好，供你对照，不是各家宿主的重新测试记录。宿主怎么装见包根 [README](../../README.md)「各宿主怎么装、怎么叫」。

## 第 0 步：准备

- 新建一个工作文件夹，把本目录的 `input.md` 拷进去，再建一个空文件夹 `notes/`。
- 准备一份派收记录：一个文本文件或一张表都行。

## 第 1 步：提目标（写清做到什么算完）

验收标准，先写下来，后面逐条对照：

1. 结果放在 `notes/会议要点.md`。
2. 「决定」一节：会上定下的决定，共 3 条。
3. 「行动项」一节：共 3 条，每条写清谁、做什么、几号前。
4. 不加转写里没有的内容；会上说「没定」的事，不写成决定。

## 第 2 步：分工（派之前先登记）

在派收记录里写一行「待收」（完整写法见 [`register-lines.md`](register-lines.md) 分支 A 第一行）：

```
待收｜任务标识：M-01｜什么活：把 input.md 的会议转写整理成要点｜谁在干：助手甲｜谁来收：我｜预计交时：2026-11-11 14:30｜到点谁查／是否在线：我，在线｜结果放哪：notes/会议要点.md｜做到什么算完：决定 3 条、行动项 3 条（每条有谁／做什么／几号前）、不加转写里没有的内容、未定事项不写成决定｜建议下一棒技能：evidence-before-done
```

## 第 3 步：派活（可复制指令）

把下面这段原样发给执行人（AI 助手或同事）：

```
请把 input.md 里的会议转写整理成要点，存到 notes/会议要点.md。
要求：
1. 「决定」一节：列出会上定下的全部决定。
2. 「行动项」一节：每条写清谁、做什么、几号前。
3. 不添加转写里没有的内容；会上说没定的事，不要写成决定。
接下这件活时回一句「接单」；做完回一句：文件路径＋各节条数。
```

对方回「接单」→ 追加 `已接单｜任务标识：M-01｜…`。这时**只是接住了**，成果还没到，M-01 仍在未完清单里。

## 第 4 步：到点查（交接）

预计 14:30，到 14:35 去 `notes/会议要点.md` 看：

- 文件在 → 追加 `已收到成果｜任务标识：M-01｜…｜待核`。仍在未完清单里（待核）。
- 文件不在 → **不写**「已收到成果」。没跑完写「续期」（原预计保留）；放错地方写「退回」（见 [`register-lines.md`](register-lines.md) 最后一节）。对方说「好了」但你没看见文件，也算没收到。

## 第 5 步：核对（evidence-before-done）

打开 `notes/会议要点.md`，对照第 1 步四条，逐条打勾：

| 验收条 | 怎么核 | 对 `output-ok.md` | 对 `output-missing.md` |
|---|---|---|---|
| 1 结果位置 | 文件在 `notes/会议要点.md` | ✓ | ✓ |
| 2 决定 3 条 | 对照转写里「定了／就定」的三处 | ✓ 3／3 | ✗ 多了一条「换办公室」 |
| 3 行动项 3 条含人和日期 | 对照转写里三个「我来／你出／你整理」 | ✓ 3／3 | ✗ 2／3，缺老许那条 |
| 4 不加料、未定不当决定 | 每条都能在转写里找到原话 | ✓ | ✗ 同第 2 条 |

## 第 6 步：判断

- **全对（分支 A）**：追加 `已验收｜任务标识：M-01｜…｜怎么核的：…｜关闭`。M-01 到这里才退出未完清单。成果对照 [`output-ok.md`](output-ok.md)。
- **缺项（分支 B）**：追加 `退回`，写清缺什么、新预计，告诉执行人；M-01 继续留在未完清单。补交后再记「已收到成果」，**只补核改动的部分**（这里是「决定」和「行动项」两节），其余段落和上次核过的一样就复用上次的核验，然后记「已验收」。完整几行见 [`register-lines.md`](register-lines.md) 分支 B。

走到这里，你已经用本包完成了一件实际小任务：有输入、有成果、有证据、有验收，也练过一次退回。
